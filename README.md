# Jiarui Han's personal website

Source for [billhan01.github.io](https://billhan01.github.io), built with Jekyll and GitHub Pages.

## Content

- Homepage translations: `_data/languages.yml`
- Homepage: `_pages/about.md`
- CV: `_pages/cv.md`
- Portfolio: `_portfolio/`
- Blog posts: `_posts/`
- Site settings and profile links: `_config.yml`

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.
